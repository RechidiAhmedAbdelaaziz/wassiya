# Wassiya.fr - Islamic Will Generator

A modern, privacy-focused React TypeScript application for creating Islamic wills (wassiya) in French.

## Features

-   ✅ **Privacy First**: All data stored locally - nothing sent to servers
-   ✅ **Islamic Compliance**: Based on Shariah principles
-   ✅ **Multi-step Form**: Easy-to-follow wizard interface
-   ✅ **PDF Export**: Download your will in a printable format
-   ✅ **Responsive Design**: Works on all devices
-   ✅ **Modern UI**: Clean, accessible interface with Tailwind CSS

## Tech Stack

-   **React 18** with TypeScript
-   **Vite** for fast development
-   **Tailwind CSS** for styling
-   **React Router** for navigation
-   **Zustand** for state management
-   **React Hook Form** with Zod validation
-   **Lucide React** for icons
-   **jsPDF** for PDF generation

## Getting Started

### Prerequisites

-   Node.js 18+ and npm

### Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open your browser to `http://localhost:5173`

## Available Scripts

-   `npm run dev` - Start development server
-   `npm run build` - Build for production
-   `npm run preview` - Preview production build
-   `npm run lint` - Run ESLint

## Form Sections

1. **Personal Information** - Basic details and identity
2. **Religious Declarations** - Shahada and faith statements
3. **Funeral Preferences** - Washing, shroud, and preparation
4. **Janaza Prayer** - Prayer preferences and location
5. **Burial Preferences** - Cemetery and burial wishes
6. **Debts & Obligations** - Outstanding debts and zakat
7. **Assets & Inheritance** - Property and possessions
8. **Final Supplication** - Personal message and dua
9. **Review & Download** - Final review and PDF generation

## Privacy & Security

-   **No Server Storage**: All data remains on your device
-   **Local Storage Only**: Uses browser's localStorage API
-   **No Tracking**: No analytics or tracking scripts
